Reference: Cambridge Cluster Database canonical LJ104 minimum
(Doye-Wales 1995, Wales-Doye 1997).

The submitted configuration is the Doye2 C2v Marks-icosahedral global,
obtained by procedural removal of 43 atoms from a 147-atom Mackay M=3
icosahedron along a 2-fold axis (C2v-symmetric seed), followed by
broad and then focused parallel basin-hopping. The icosahedral
competitor at -582.038429 (≈0.048 ε above the global) was reached
first by broad search; the Doye2 basin was entered from a focused BH
run at T=0.7 with twin-plane / rotation-graft / high-energy-atom moves.

Candidate coordinates (`coords.xyz`) and the submission `energy.txt` are
included alongside this README.
